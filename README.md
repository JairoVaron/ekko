# Plataforma de Comunicación Social en Tiempo Real

## Descripción

Aplicación web desarrollada con Java y Spring Boot que permite implementar funcionalidades de comunicación social mediante una interfaz web y mecanismos de actualización en tiempo real.

## Tecnologías utilizadas

- Java 21
- Spring Boot
- Maven
- PostgreSQL / Supabase
- Spring Security
- Thymeleaf
- WebSocket y STOMP

## Requisitos

- Java 21
- Maven
- Una base de datos PostgreSQL configurada

## Configuración y ejecución

1. Clonar el repositorio.
2. Configurar las variables de conexión a la base de datos.
3. Ejecutar el proyecto desde el entorno de desarrollo o mediante Maven:

   ```bash
   ./mvnw spring-boot:run
   ```

   En Windows, puedes utilizar:

   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

4. Abrir en el navegador la dirección local configurada para la aplicación.
